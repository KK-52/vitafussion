🎓 Launch Training

Train the ECG Encoder directly on PTB-XL. Run the command below in your terminal. The --quick flag performs a fast 2-epoch dry-run to verify the pipeline before full training.

Quick dry-run (verify pipeline)
$
python train_ecg.py --quick
Full training (50 epochs, 100 Hz records)
$
python train_ecg.py \
  --ptbxl_dir data/ptbxl \
  --epochs 50 \
  --batch_size 64 \
  --label_mode arrhythmia
High-res 500 Hz training (GPU recommended)
$
python train_ecg.py \
  --ptbxl_dir data/ptbxl \
  --sampling_rate 500 \
  --epochs 50 \
  --batch_size 32
📦 Dataset Setup

PTB-XL must be downloaded manually from PhysioNet (~2.6 GB). Follow these steps:

  1. Register / sign in at physionet.org
  2. Go to the PTB-XL 1.0.3 page
  3. Download and extract to vitafusion/data/ptbxl/
  4. Or set the PTBXL_DIR env variable in your .env file

The directory should contain:

ptbxl/
  ptbxl_database.csv
  scp_statements.csv
  records100/  # 100 Hz ECG waveforms
  records500/  # 500 Hz ECG waveforms
Install required dependencies
$
pip install wfdb tqdm scikit-learn
